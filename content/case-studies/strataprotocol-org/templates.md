The STRATA implementation-template prompts are public in the [strata-protocol-docs repository](https://github.com/FlorantePascual/strata-protocol-docs){target="_blank" rel="noopener"} under `docs/_templates/`. Each turns the governed method into repeatable AI delivery scaffolding for a specific stack. Every link opens in a new tab. More templates will be added over time.

This platform was built under STRATA Protocol v1.0, which numbered requirements `REQ-NNN`, and its records keep those identifiers; FR-001 is its first [Feature Release](/documentation/reference#feature-release) under STRATA Protocol v1.2.

- [Frontend (FE) prompts](https://github.com/FlorantePascual/strata-protocol-docs/blob/main/docs/_templates/FE/prompts.md){target="_blank" rel="noopener"} — prompt scaffolding for Vue single-page-application frontends.
- [Backend (BE) prompts](https://github.com/FlorantePascual/strata-protocol-docs/blob/main/docs/_templates/BE/prompts.md){target="_blank" rel="noopener"} — prompt scaffolding for NestJS API backends.
- [Nuxt prompts](https://github.com/FlorantePascual/strata-protocol-docs/blob/main/docs/_templates/NUXT/prompts.md){target="_blank" rel="noopener"} — prompt scaffolding for Nuxt and Docus documentation platforms.

These templates are the same scaffolding used to build StrataProtocol.org. See the [Artifact Trail](/case-studies/strataprotocol-org/artifact-trail) for the governance documents they produced.

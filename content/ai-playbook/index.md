The AI Playbook guides practitioners through working effectively with AI coding assistants — GitHub Copilot, Cursor, Claude Code, and similar tools — within the STRATA governance framework. It covers session setup, authority chain mandates, prompt structures, escalation handling, and governed delivery patterns that keep AI-assisted work traceable, recoverable, and defensible.

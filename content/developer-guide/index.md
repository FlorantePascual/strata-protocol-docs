The Developer Guide is your implementation toolkit for the STRATA Protocol — the practical companion to the framework documentation. Where the Documentation explains what STRATA is and why each stratum matters, the Developer Guide gives you the exact templates to apply it on a real project with a real AI coding tool.

## What You Get

The Guide delivers three resource types that accelerate STRATA adoption:

**Implementation Templates** — Copy-pasteable governance document templates for every stratum, derived from the actual artifact trail that built StrataProtocol.org. Classification Records, BRDs, PRDs, Engineering Standards documents, Implementation Plans, and Implementation Manifests — each with prose guidance, worked examples from real projects, and stack-specific variants for Nuxt/Docus, NestJS, and Vue.

**Guided Workflows** — Step-by-step procedures showing how a human engineer and an AI coding tool collaborate within the STRATA framework. Each workflow covers the full human-gate cycle: analysis, AI-assisted delivery, and verification sign-off.

**Reference Architecture** — The annotated technical architecture of StrataProtocol.org itself, with decision records, stack rationale, and RBAC patterns. A reference implementation for teams building Nuxt/Docus documentation platforms, NestJS backends, or Vue frontends under STRATA governance.

## Template Quality Standard

Every template in this guide meets a single quality bar: **functional immediately, not placeholder stubs**. You should be able to copy a template, fill in your feature details, and have a usable STRATA-compliant governance artifact within 30 minutes — no adaptation required.

These are the exact templates used to build this platform. They are proven, real-world, and production-tested.

## Using This Guide

Work through the [Deep Dives](/documentation/deep-dives) in parallel — each deep-dive explains a stratum procedurally, and the corresponding Developer Guide templates give you the actual documents to produce. Start with the [Introduction](/developer-guide/introduction) to understand the three-step process (analysis → implementation plan → execution), then select the template set that matches your stack.

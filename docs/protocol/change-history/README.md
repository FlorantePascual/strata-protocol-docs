# Change history

Each version of the STRATA Protocol is produced by a findings register: a review
that names a location in the protocol text, quotes it, states why it was a
defect, and gives the replacement. The registers are the reasoning behind every
entry in [`CHANGELOG.md`](../CHANGELOG.md).

| Register | Produced | Status in this repository |
|---|---|---|
| `01-recommendations.md` | STRATA Protocol v1.1 | **Withheld** until an anonymized version is available: it identifies the production project its findings came from |
| `02-refinements.md` | STRATA Protocol v1.1 | **Withheld** until an anonymized version is available: it identifies the production project its findings came from |
| [`03-protocol-correction-recommendations.md`](./03-protocol-correction-recommendations.md) | STRATA Protocol v1.2 | **Published, complete.** All seven findings, as applied |

The changelog links registers 01 and 02 by name. Those two links do not resolve
in this repository until the anonymized versions are published. What each
register changed is recorded in full in the changelog's v1.1 entry.

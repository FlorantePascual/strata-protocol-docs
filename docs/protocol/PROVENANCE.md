# Provenance of `docs/protocol/`

**Release 1.1.0 · STRATA Protocol v1.1**

[`README.md`](./README.md) in this folder is the STRATA Protocol v1.1 overview.
v1.1 was stamped on 2026-08-06 and applied in practice before it was released
here. This retroactive release archives it between release 1.0.0 (v1.0) and the
next release.

**The text is a reconstruction.** The author's working copy of v1.1 predates
three amendments made to v1.1 after its stamp date. The final v1.1 text was
rebuilt from that copy, from the v1.2 text that inherited the amendments, and
from the published list of changes between the two. The reconstruction was
checked against the v1.1 line numbers that the v1.2 correction record cites, and
every cited line resolves to the text quoted there. Wording changes that left
the line count unchanged, and that neither change list records, cannot be ruled
out.

The overview's own "What changed in v1.1" section is the change record for this
version. Later versions keep their history in a separate changelog.

For the current version of the protocol, see
[strataprotocol.org](https://strataprotocol.org) and the latest release of this
repository.
